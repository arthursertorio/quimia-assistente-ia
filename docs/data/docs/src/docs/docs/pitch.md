# 🧪 Pitch — QuimIA

O QuimIA é um assistente virtual baseado em Inteligência Artificial desenvolvido para auxiliar estudantes de Engenharia Química.

O projeto surgiu a partir de um problema comum na graduação: a necessidade de consultar diferentes materiais para compreender conteúdos de diversas disciplinas.

A solução utiliza uma inteligência artificial associada a uma base de conhecimento organizada.

O estudante faz uma pergunta e o sistema utiliza as informações disponíveis para gerar uma resposta contextualizada.

Um dos principais objetivos é reduzir respostas inventadas. Quando a informação necessária não está disponível na base, o assistente deve informar que não possui dados suficientes.

O protótipo foi desenvolvido em Python utilizando Streamlit e uma API de inteligência artificial.

O sistema foi avaliado por meio de perguntas relacionadas aos conteúdos da base e perguntas para verificar seu comportamento diante de informações ausentes.

O QuimIA não substitui professores ou livros. Ele funciona como uma ferramenta complementar de apoio aos estudos.

Como evolução futura, o projeto poderá receber documentos PDF, busca semântica, embeddings, RAG, histórico de estudos e recomendações personalizadas.

O objetivo final é demonstrar como Inteligência Artificial pode ser aplicada a uma necessidade acadêmica real.
